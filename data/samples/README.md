# Muestras de datos

Esta carpeta se mantiene vacía por defecto: la aplicación consume los datasets de trabajo desde una ubicación externa (`TelemetryDataRoot`) o desde un paquete de demostración desplegado. No copies aquí telemetría completa, datos derivados sensibles ni credenciales.

Antes de añadir una muestra al repositorio, verifica que sea necesaria y que las condiciones de uso permitan redistribuirla. Manténla pequeña, reproducible y anonimizada cuando corresponda. Acompáñala con procedencia, atribución, licencia, esquema/unidades y el procedimiento utilizado para extraerla o generar una versión sintética. La licencia del código no otorga derechos sobre los datos.
